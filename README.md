# Intelligent Document Classification System

## Project Description
This project classifies news articles into different categories using Machine Learning and Natural Language Processing (NLP).

## Categories
- Business
- Entertainment
- Politics
- Sport
- Technology

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes

## Dataset
BBC News Dataset

## Performance
- Accuracy: 96%
- Precision: 96%
- Recall: 96%
- F1-Score: 96%

## Project Workflow
Dataset → Preprocessing → TF-IDF → Naive Bayes → Prediction → Evaluation

## Example
Input:
Virat Kohli scored a century against Australia

Output:
sport
